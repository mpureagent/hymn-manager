# 领域术语（mattpocock GLOSSARY 约定：只记术语定义与已核实事实，不写未定项为事实）

## 诗歌本（book）

一本实体诗集的数字化集合。**俗称与真名不同**，产品里两者都要能用：用户说"红本"，界面上要能对上《赞美诗（新编）》。

| 俗称 | 真名 | 首数 | 状态 |
|---|---|---|---|
| 红本 | 《赞美诗（新编）》 | 400 + 短歌 42 | ✅ 已核实 |
| 蓝本 | ？（待定，候选见 docs/research/hymn-data-sources.md） | ? | ⏳ 待用户确认 |
| 千首本 | ？（很可能是《赞美诗歌》1218 首，但该本俗称"黑皮诗歌本"） | ? | ⏳ 待用户确认 |

## 诗歌（hymn）

一首诗在某本诗歌本里的条目。身份 = `(book, number)`，**不是标题**：同一首在不同本里编号不同、标题译法不同、分段不同。

## 编号（number）

用户口语的"第几首"，等于实体书目录序号，1 起。检索输入纯数字时优先按编号命中。

## 标题 / 首句（title / first line)

红本目录写法是「圣哉三一」，会众口语常是「圣哉圣哉」。标题与首句都要能检索；用户举例"第1首圣哉圣哉"即此现象。

## 历史记录（history）

用户检索/上屏过的诗的按时间倒序列表。作用域与保留策略待 spec 定。

## 投屏（project / display）

把当前诗歌推到一个全屏展示窗口（第二显示器/投影）。文字模式可配样式；图片模式只是整图上屏。
