## 四、PM 追加修复：HTML 双份复制（`c998b7b`）

T10 让 `src/control/web.html` 复制了 `index.html` **1769 行**，两者只差 1 行（脚本入口 `./main.ts` vs `./web-boot.ts`）。同样 `web.html` 与 `projection.html` 也各复制一份。

这意味着**以后每改一行 CSS 都要同步改两处**，迟早漂移——正是「一套代码两宿主」要避免的事。

修法：新增 `scripts/gen-web-html.mjs`，在 `build:web` 前从 `index.html` 派生 `web.html`（只替换脚本入口），产物进 `.gitignore`。现在只需维护一份 HTML。

验证：派生后 diff 仅 1 行差异；145 测试全绿；两端构建均成功；手机端与宽屏行为不变。
