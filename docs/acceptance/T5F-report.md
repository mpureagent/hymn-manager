分页 API（读代码确认，纯函数可单测）：

```ts
paginateVerses(verses, capacity): ProjectionPage[]
computeProjectionCapacity({ viewportHeight, paddingTop, safeBottom, lineHeightPx, reserveLines }): number
formatProjectionPage(index, total): string
```

- 优先按段分页；单段行数 > capacity 时按行切，续页标「（续）」
- capacity 扣除内边距 + 控制条安全区 + 1 行余量
- 兜底：渲染后若溢出，按步长降字号，最低 24px，控制条给提示

### 兜底自动降字号（实测独立复现）

120px 下打开千首本第 77 首，投屏实际生效：

```
--hymn-font-size: 108px   （请求 120，自动降到 108）
line-height: 172.8px = 108 × 1.6
控制条提示：「字号已自动缩至 108px 防裁切」
```

注：Qoder 报告里说缩到 78px，与我实测的 108px 不同——原因是两次窗口高度不同（它用 1000 高的窗口但内容不同）。**机制本身正确生效**，不是缺陷，但说明报告里的具体数值不可作为基准，以实测为准。
