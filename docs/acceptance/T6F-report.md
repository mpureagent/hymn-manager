## 三、PM 追加修复：元信息白名单（防误删）

Qoder 删掉了 634 行标题行。我核对时发现第 627 首仍残留 `音乐人：宣道出版社合唱团`——它的 META 规则没有「音乐人」这个键。

但我没有直接加一个键，而是先扫了全库所有「行首中文+冒号」的行，结果发现**大量真歌词也长这样**：

```
神未曾应许：天色常蓝，
主说：”牧人必须流血，
慈声对我说：“我总离不开你。”
问主：“山径沿途血迹，
耶稣说：只要相信我的人
```

如果按「任意中文+冒号」的宽规则过滤，会直接删掉这些歌词。因此改为**键名白名单 + 值长度 ≤25 字**：

```
歌手|专辑|词|曲|作词|作曲|词曲|谱曲|演唱|编曲|制作|出品|出品人|监制|
混音|录音|音乐人|歌词编辑|编辑|QQ|微信|邮箱|电话|口白|和声|指挥|司琴
```

验证：**23 条带冒号的真歌词全部保留**（红本 21 条 + 千首本 2 条），元信息残留降为 0。

这条经验值得写进数据管线规范：**清洗规则必须先扫全集再定，不能看到一条补一条**——补漏时最容易顺手把正文一起删掉。
