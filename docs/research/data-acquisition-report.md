## 重要发现：同标题 ≠ 同歌词

用 `PraisePoetry1608` 做交叉核对，642 首同名歌中，两本歌词相似度**中位数仅 0.57**，只有 14% 达到 0.8 以上；少数（如 254《教会根基》）完全不是同一版本译文。

→ 产品后果（已写进 spec 约束）：

1. **不能用跨本同名去补数据**。因此 1218 里 24 首缺歌词的**不自动填充**，标为"仅有目录、歌词待补"。
2. **跨本检索必须带来源标识**。同一标题在两本里是两条不同记录，编号也可能撞。
3. 红本第 1 首官方目录名「圣哉三一歌」、1218 第 1 首是「圣哉三一」但**歌词完全不同**（红本译"全权的神明"，1218 译"全能大主宰"）——这正是必须支持"按首句检索"的实证。

## 复现

```bash
python3 tools/scrape_songbook.py hymns-red 4 .raw/442_index.json     # 红本目录
python3 tools/scrape_songbook.py hymns-bk  9 .raw/1218_index.json    # 1218 目录
git clone --depth 1 https://github.com/AlanQtten/hallelujah .raw/hallelujah
python3 tools/crawl_songs_par.py 21750 23200 .raw/j51_songs.jsonl 8 0.15  # 1218 歌词
python3 tools/crawl_scores.py black .raw/1218_index.json .raw/scores 1 1300 6  # 1218 曲谱
python3 tools/crawl_scores.py red   .raw/442_index.json  .raw/scores 1 1100 6  # 红本曲谱
python3 tools/build_dataset.py all                                   # 生成 data/books/*.json
```

耗时实测：曲谱全量 1659 张约 18 分钟（6 并发），歌词 1176 条约 12 分钟（8 并发）。
