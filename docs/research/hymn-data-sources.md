# 诗歌本真名与数据源调研

> 调研时间：2026-10-22。每条结论标注证据与置信度。**未证实的不要当事实用。**

## 一、三本诗歌本的真名

### 1. 红本 = 《赞美诗（新编）》 ✅ 已确认（高置信）

- 全名《赞美诗（新编）》，英文 The Chinese New Hymnal，中国基督教三自爱国运动委员会 / 中国基督教协会 1983 年 4 月出版，正文 400 首 + 短歌 42 首 = 442 首，409 页。
  来源：<https://zh.wikipedia.org/wiki/赞美诗（新编）>
- 俗名"红本"有站点明文记载：「三自最常用的诗歌本，**也称红本诗歌本**」——爱赞美《新编赞美诗（五线谱）》歌本页 <https://www.j51.net/songbook/25.html>
- 封面实测（本仓库下载核对了封面图）：深红漆布面、金漆字「赞美诗 · 新编」。与"红本"完全对得上。
- 相关但**不是**红本：《赞美诗（新编）补充本》2009 年出版，200 首，实际封面为橄榄/土黄色，非蓝色。
  来源：<https://www.ccctspm.org/cppccinfo/14058>、爱赞美补充本页封面图

### 2. 千首本 = ？（中置信，待用户确认）

- 网络上"千首本"实际多指《赞美诗歌》系列（1218 首）：歌谱站的"千首本歌谱（幻灯片放映，pps 格式）"即 1218 首的投影文件；搜索联想词里"千诗诗歌 1218 首"常与"千首本"同现。
  来源：<https://www.iwtfly.com/56-mei-dang-wo-zhan-ang-ni-2.html>（原文："若需千首本歌谱（幻灯放映，格式：pps）…QQ 注明：千首本"）
- 但《赞美诗歌（1218 首）》由**浙江舟山基督教两会**出版发行，俗称是"**黑皮诗歌本**"——爱赞美专辑页原文 <https://www.izanmei.cc/album/zan-mei-shi-ge-1001-1218.html>。封面实测也是黑色。所以"千首本=1218"与"俗称黑皮"并存，需用户指认。
- 其它"近百首/千首"候选：《赞美诗选编（1050 首）》、《赞美诗歌（1300 首）》、《赞美诗歌（1608 首）》、《大家歌唱》（1000 首）、《赞美诗歌（1384 首）》。

## 二、网络资源是图片还是文字

实测（2026-10-22）：

| 站点 | 内容 | 形态 |
|---|---|---|
| 爱赞美 j51.net / zanmei.ai | 50+ 本诗歌本，按本分首 | **歌谱=图片**（简谱 PNG，如 `file.izanm.org/...png`）；歌词另有独立页面 |
| 赞美诗歌歌谱中心 godgepu.cn / gepu.kyhs.me | 选本 1050、1218 等 | 同样以歌谱图片为主，另有 pps 投影包 |
| 学圣诗 xueshengshi.com | 新编赞美诗逐首 | 文本+歌谱，偏诗班教学 |
| GitHub | 零散项目（如 `cmeng-git/hymnchtv`、`godhelpgrace/praise-songs`、`esojourn/ChineseHymn`） | 有歌词文本/JSON，但覆盖面与准确度未审 |

结论：

1. **歌词文本可得**，但要逐首抓/校对（繁体简体、异体字、"祢/你"、分段、副歌标记都不统一）。
2. **简谱只能拿到图片**。想要"矢量/可排版歌谱"就得 OCR + 重排（成本高，另立项）。
3. 因此产品分两层展示：**主显示=文字歌词（可配字号/字体/颜色/背景）**，**附加=歌谱图片视图**。文字路径才是精致排版的那条路。

## 三、风险

1. **版权**。《赞美诗（新编）》歌词曲谱版权属中国基督教两会；1218 属舟山两会。内置全文并公开发布（GitHub Release）有侵权风险。
   - 默认方案：软件本体开源、**不带数据**；提供"诗歌本数据包"导入（`.hymnpack` zip+json），数据包由本地生成脚本产出、不公开分发。
   - 备选：只在私有仓库内置数据，Release 只发程序。
2. **数据准确性**。诗歌本常有"第 1 首 圣哉三一 / 圣哉圣哉"这类叫法差异（用户举例"第1首圣哉圣哉"，官方目录是"圣哉三一"），检索必须支持别名/首句检索，不能只靠标题精确匹配。
3. **同名不同本**。同一首诗在三本里编号不同、歌词分段也不同，跨本检索要能区分来源，不能混号。
