# 赞美诗歌本桌面端 · 产品规格 v1

状态：待实施（PM 已定稿，用户已确认 5 项决策）
日期：2026-10-22

## 1. 问题与目标

聚会前要在几十秒内找到一首诗并上屏。现有工具要么是手机 App（投屏不便），要么是 PPT 手工拼页（找不到、改不动）。

目标：Windows 桌面应用，**离线**，选本 → 检索 → 看 → 投屏，全程键盘可操作。

## 2. 范围

### 2.1 本轮做

| 能力 | 定义 |
|---|---|
| 选本 | 红本、千首本（黑本）二选一，**不做跨本混合检索**（用户决策） |
| 检索 | ①编号（输入 `1`）②标题模糊 ③首句模糊；结果分组排序 |
| 阅读 | 左侧结果列表 + 右侧歌词预览（用户决策） |
| 历史 | 搜索词最近 20 条（可点回填）+ 打开过的诗歌最近 50 条 |
| 样式 | 全局一套：字体、字号、文字色、背景色（用户决策） |
| 投屏 | 独立全屏窗口，主窗口可继续操作（用户决策） |
| 曲谱 | 每首的简谱原图，独立视图 + 缩放 |

### 2.2 本轮不做（明确排除）

- 跨本检索与合并（用户已否决）
- 每首独立的样式偏好
- 音频播放、歌单编排、多机同步、移动端
- 曲谱 OCR 重排（要另立项）
- 蓝本（真名未核实，用户同意搁置）
- 编辑/新增诗歌（数据由数据包提供）

### 3.2 数据包格式

程序**不内置数据**（版权）。运行时从数据包目录读：

```
hymns-data/
  manifest.json          { version, books: [{id,name,alias,count}] }
  books/
    red_book.json        { book, name, alias, items: [...] }
    black_book_1218.json
  scores/
    red/0001_0.jpg
    black/0001_0.png
```

查找顺序：`<exe 同目录>/hymns-data` → `<userData>/hymns-data` → 开发态 `./hymns-data`。找不到则显示"未安装数据包"引导页（给出放置路径），不崩溃。

`item` 结构（已定）：
```json
{ "number": 1, "title": "圣哉三一歌", "title_official": "圣哉三一歌",
  "verses": [ { "label": "1", "lines": ["...", "..."] } ], "source": "..." }
```

## 4. 交互规格

### 4.1 主窗口布局

**选本与检索是两个独立的控件，不混在搜索框里**（用户明确要求）：

- 选本 = 搜索框**左侧的独立下拉框**，列出所有可用诗歌本（显示"红本《赞美诗（新编）》"这种 别名+真名 形式）。选中即切换当前本，列表与检索范围随之切换。
- 搜索框 = **只搜当前已选本内部**的诗歌。不解析书名，不做"输入书名切本"。用户输入一律视为编号或歌名关键字。

```
┌─────────────────────────────────────────────────────────┐
│ [▼ 红本《赞美诗（新编）》] [ 搜索编号或歌名        ] [样式][投屏]│
├──────────────┬──────────────────────────────────────────┤
│ 结果列表      │  歌词预览                                  │
│ 第1首 圣哉三一│  第1首  圣哉三一歌                        │
│ 第2首 …       │  1. 圣哉，圣哉，圣哉！全权的神明            │
│              │     清晨我众歌声，穿云上达至尊              │
│ 历史 ▸        │  [歌词] [曲谱]  ← 视图切换 tab             │
└──────────────┴──────────────────────────────────────────┘
```

下拉框内容来自数据包 `manifest.json` 的 `books` 数组，顺序即显示顺序。切换本 → 搜索框清空、列表回到该本全目录、记住选择（写 settings.json）。

- 窗口最小 1024×640。宽度 < 900px 时折叠为单栏（列表/预览切换）。
- 键盘：`/` 或 `Ctrl+F` 聚焦搜索框；`↑/↓` 移动选择；`Enter` 打开选中；`Esc` 清空搜索；`F5` 或 `Ctrl+P` 投屏当前首。

### 4.2 检索

输入即搜（防抖 120ms）。归一化：NFKC → 去空格标点 → 可选去尾「歌」。

匹配优先级（高分在前）：
1. 输入为纯数字且等于某首编号 → 该首置顶，标「编号命中」
2. 标题前缀匹配
3. 标题包含
4. 首句（第一段第一行）包含
5. 别名/口语包含

显示：编号 + 标题 +（命中首句时）该行摘录，命中片段高亮。

空查询 → 显示当前本的完整目录（虚拟滚动，1200+ 条要流畅）。

### 4.3 历史

- **搜索词**：仅记录"有效搜索"（有结果且停留 >1s，或用户按下 Enter/点了某条），去重保序，上限 20。
- **打开记录**：打开某首即记录（book, number, title, 时间），同首重复打开只更新时间并置顶，上限 50。
- 存 `<userData>/history.json`，`{ searches: [], opened: [] }`。可一键清空。
- 在侧栏「历史」区显示打开记录最近 10 条，完整列表可展开。

### 4.4 歌词预览

- 段落渲染：段号（如有）小字，行间距 1.6。
- 缺歌词（红本短歌 42 首、1218 缺 24 首）→ 显示「本首歌词暂缺」+ 曲谱按钮（有图时可用）。
- 点击某行可"从此行投屏"（投屏窗口从该段开始滚动）——P1，可延后。

### 4.5 曲谱视图

- tab 切到「曲谱」时显示 `<img>`，等比适应可用高度，可 `+/-` 缩放（50%–300%），可拖拽平移，滚轮缩放（Ctrl+滚轮）。
- 无曲谱图 → 提示「无曲谱」。

### 4.6 样式设置（全局）

面板项：字体（系统字体下拉 + 常用中文字体候选）、字号（24–120px，步进 2）、文字色、背景色（色板 + 取色器）、行距、对齐（居中/左对齐）。

- 实时预览：改动立即作用于预览区。
- 持久化 `<userData>/settings.json`，启动恢复。
- 提供 2–3 个预设（浅底深字 / 深底浅字 / 暖色底），一键切换。

### 4.7 投屏窗口

- 独立 `BrowserWindow`，`fullscreen` 在指定显示器（默认非主屏；无第二屏时在主屏全屏）。
- 内容与主窗口解耦：主窗口切歌 → 投屏窗口同步；投屏窗口本身无 UI 元素（鼠标移动时才浮出极简控制条：上一首/下一首/退出）。
- 投屏窗口内可 `PgUp/PgDn` 或 `↑/↓` 翻段（长歌分段翻页），`Esc` 关闭。
- 主窗口关闭 → 投屏窗口一并关闭。

## 5. 非功能要求

- **离线**：无任何网络请求。启动不联网。
- 启动到可检索 ≤ 1.5s（1200 首全量载入 + 建索引）。
- 检索响应 ≤ 50ms（1200 首规模）。
- 曲谱图解锁后按需加载，不预载全部（避免 200MB 常驻内存）。
- 数据只读；不在程序目录写文件（除开发态）。

## 6. 技术约束

见 `docs/adr/0001-stack.md`、`docs/adr/0002-data-pack.md`。

- Electron 22.3.27（与 bible-projector 同基线，镜像已验证）
- TypeScript 5.6 + Vite 5 + vitest 2
- 渲染层 vanilla DOM 模块（不用 React；沿用 bible-projector 已跑通 198 测试的形态）
- 持久化用 JSON 文件，**不用 better-sqlite3**（避免 native 模块在 Electron 下 rebuild 的坑；数据量仅几十条）

## 7. 验收标准（PM 逐条实测）

1. 选红本 → 输入 `1` → 首条是「第1首 圣哉三一歌」，且标注编号命中。
2. 输入「圣哉」→ 两本各自都能命中（分别验证，不跨本）。
3. 红线用例：输入 1218 第 1 首的首句「全能大主宰」→ 能搜到 1218 第1首；在红本下搜同一句 → 搜不到红本第1首（证明没有把两本当同一本）。
4. 打开过的诗出现在历史；重启应用后历史仍在。
5. 改字号/背景色 → 预览立即变；重启后保持。
6. 点投屏 → 第二窗口全屏显示同一首；主窗口切歌，投屏跟随。
7. 曲谱 tab 显示简谱图，可缩放。
8. 拔网线全流程可用。
9. 打包含数据包时体积与启动时间达标；程序目录不含数据（数据包独立）。

## 8. 风险

| 风险 | 处置 |
|---|---|
| 曲谱图为扫描件，投影时小字看不清 | 缩放 + 拖拽；长歌提示用歌词视图 |
| 1218 有 24 首无歌词 | 显示"歌词暂缺"，不静默出错 |
| 数据版权 | 程序与数据包分离；仓库只存脚本 |
| 中文模糊检索易"搜不到"（异体字/祢你） | 归一化 + 首句检索；建同义表（祢/你、祂/他）作为 P1 |
