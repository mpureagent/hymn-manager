# T2 检索（编号 / 标题模糊 / 首句）

**Blocked by**: T1
**Blocks**: T3

## 背景

核心功能。用户三种输入：`1`、`圣哉`、以及口语首句。归一化与排序必须是**可单测的纯函数**，不依赖 DOM。

## 必读

- `docs/specs/hymn-manager-spec.md` §4.2
- `docs/GLOSSARY.md`（编号 / 标题 / 首句 的定义）

## P0 必做

1. **归一化 `shared/normalize.ts`**
   - NFKC 全半角统一；去空白与中英标点；可选去尾「歌」。
   - 导出 `normalizeQuery(s)` 与 `normalizeText(s)`（同一套规则，保证两侧一致）。
   - 同义字折叠：`祢→你`、`祂→他`、`裏→里`、`著→着`（简体侧统一）。**只影响匹配，不改原显示文本。**

2. **检索范围：只在当前已选本内**
   - `search(items, rawQuery, opts)` → `Array<{ item, score, kind, excerpt? }>`，`items` 由调用方传入**当前本的条目数组**。
   - 检索函数内**不出现书名、不做跨本合并**（用户已决策：先选本，不跨本）。
   - 不得从查询文本里识别书名并自动切本——切本只有顶部下拉框一个入口。
   - 纯数字输入：等于某编号 → 该首排首位，`kind='number'`。
   - 其余按 §4.2 的 5 级优先级打分；`kind` 取 `number | title-prefix | title-contains | firstline | alias`。
   - 命中首句时返回 `excerpt`（该行原文）。
   - 空查询返回全部（原顺序）。
   - 单测至少覆盖：
     - `1` → 红本返回第1首且 kind=number
     - `圣哉` → 红本命中第1首（标题「圣哉三一歌」）
     - 红本搜「全能大主宰」（1218 第1首的首句）→ **不命中红本第1首**（防跨本串味）
     - 1218 搜「全能大主宰」→ 命中第1首且 kind=firstline
     - 「祢」与「你」互搜能命中
     - 输入不存在编号 `99999` → 空结果，不报错

3. **结果列表 UI（`control/list-view.ts`）**
   - 显示：编号徽标 + 标题 +（有 excerpt 时）第二行摘录，命中片段用 `<mark>` 高亮。
   - 输入防抖 120ms。
   - `↑/↓` 移动选中，`Enter` 打开（本单"打开"=右侧预览 + 记录选中，历史在 T3）。
   - 结果为空：显示"没有找到「<query>」"+ 提示「试试输入编号，或只输入标题中的两三个字」。
   - 结果数量提示：`找到 N 首`。

4. **搜索框行为**
   - `/` 或 `Ctrl+F` 聚焦并全选；`Esc` 清空并显示全部。
   - 输入法组合输入（IME）期间不触发检索（监听 `compositionstart/end`）——中文输入必须处理，否则每敲一个字母都搜。

## P1 应做

- 首句检索命中时，在列表项显示"首句"小标签，与标题命中区分。

## 验收标准

```bash
npm run typecheck && npm test
grep -n "全能大主宰" -r src/shared/__tests__ | head   # 反例测试存在
```
- 手动：红本输入 `1` 第一条为「第1首 圣哉三一歌」；输入「圣哉」命中；切到 1218 输入「全能大主宰」命中第1首。
- 输入法：用中文输入法打「圣哉」，拼音阶段不触发检索，上屏后触发一次。
- 1200 条全量下连续输入不卡顿（列表滚动期间输入仍跟手）。

## 不含

历史记录、歌词渲染细节、投屏、曲谱。搜索词持久化属 T3。
