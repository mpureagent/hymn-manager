# T5 投屏窗口

**Blocked by**: T4
**Blocks**: T6

## 背景

投屏是本应用价值的一半：主窗口继续操作，另一块屏（投影仪）全屏显示当前诗歌。bible-projector 已跑通双窗模型，可借鉴其窗口生命周期管理，但**不做主屏劫持、不做双窗保护**等复杂形态——本单只要能用的最简投屏。

## 必读

- `docs/specs/hymn-manager-spec.md` §4.7

## P0 必做

1. **投屏窗口创建（`main/projection-window.ts`）**
   - 独立 `BrowserWindow`，加载 `projection.html`。
   - 显示器选择：优先选**非主显示器**；只有一块屏时在主屏全屏（此时给主窗口一个提示「当前仅一块屏幕，投屏将覆盖主屏」）。
   - `setFullScreen(true)`；`frame:false`、`autoHideMenuBar`、无边框。
   - 窗口关闭（用户 Esc 或点关闭）→ 主窗口的投屏按钮恢复为未激活态。

2. **内容同步（IPC）**
   - 主窗口打开某首 → 若投屏窗口存在，主动推送 `{ book, number, title, verses, style }`。
   - 样式变更（T4）→ 同步推送 style，投屏窗口即时更新。
   - 投屏窗口启动时主动拉一次当前内容（避免"先开投屏再选歌"空白）。
   - 主窗口关闭 → 投屏窗口一并关闭（`main` 里监听）。

3. **投屏渲染（`projection/`）**
   - 全屏、无 UI 元素、纯内容。
   - 复用 `shared/style.ts` 的样式应用方式（同一份 style → 同样的 CSS 变量），保证"所见即所投"。
   - 长歌词：**按段分页**。一次显示 1 段（若该段行数少可 2 段），`PgUp/PgDn` 或 `↑/↓` 翻页，底部显示 `2/4` 页码。
   - 鼠标移动时浮出极简控制条（半透明）：`上一首 / 上一页 · 页码 · 下一页 / 下一首 / 退出`，3 秒无操作自动隐藏。
   - `Esc` 关闭投屏窗口。

4. **主窗口投屏按钮**
   - 未激活：点击 → 创建/聚焦投屏窗口并推送当前首。
   - 已激活：点击 → 关闭投屏窗口（toggle）。
   - 未选中任何诗时点击 → 提示「请先选择一首诗」。

5. **快捷键**
   - `F5` 或 `Ctrl+P`：投屏当前首（与按钮等价）。

## P1 应做

- 投屏窗口记住上次所在显示器（存 settings.json）。
- 投屏时主窗口标题栏显示「投屏中」状态标记。

## 验收标准

```bash
npm run typecheck && npm test
```
- 手动（单屏环境也可验）：选中红本第1首 → 点投屏 → 出现全屏窗口显示该首，样式与预览一致。
- 主窗口切到第2首 → 投屏内容跟随变化。
- 主窗口改字号 → 投屏即时变化。
- 投屏窗口内 `PgDn` 翻段，页码更新。
- 主窗口关闭 → 投屏窗口随之关闭，无残留进程。
- 截图对比：主窗口预览区与投屏窗口同一样式（供 PM 验收）。

## 不含

曲谱视图投射（T6 决定曲谱是否可投屏）、双屏保护、劫持主屏、演讲者注释。
