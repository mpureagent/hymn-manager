# T6 曲谱视图（简谱原图 + 缩放平移）

**Blocked by**: T5
**Blocks**: T7（打包）

## 背景

每首诗歌在数据包里有一张简谱扫描图（红本 JPG 1280×1842、1218 PNG 1400×1947）。这是**图片**，无法改字体字号，只能缩放平移。定位：歌词视图是主显示，曲谱是"要看谱时"的辅助视图。

## 必读

- `docs/specs/hymn-manager-spec.md` §4.5
- `docs/research/data-acquisition-report.md`

## P0 必做

1. **数据侧**
   - 数据包 `scores/<book>/<NNNN>_<i>.<ext>` 的索引来自 `manifest` 或按文件名规则推导（`0001_0.png` → 编号 1，第 0 张）。
   - 主进程提供 `getScorePath(book, number)` → 绝对路径或 null。**只解析路径，不读文件内容**（按需加载）。
   - 渲染层用 `file://` 加载（CSP 需允许 `img-src file:`）。

2. **曲谱视图 UI**
   - 右侧预览区的 `[歌词] [曲谱]` tab 切换。
   - 曲谱 tab：`<img>` 等比适应容器高度，居中，底色与预览区一致。
   - **缩放**：`+/-` 按钮与 `Ctrl+滚轮`，范围 50%–300%，步进 10%。显示当前百分比。
   - **平移**：放大后超过容器时，按住鼠标拖动平移；或滚动条。
   - **双击**：在"适应高度"与"100%"之间切换。
   - 切歌后缩放回到"适应高度"（不记忆每首的缩放）。
   - 无曲谱图 → 显示「本首暂无曲谱」，不显示破图。
   - 图片加载失败 → 显示「曲谱加载失败」+ 文件路径（便于排查）。

3. **缺数据的情况**
   - 红本短歌 42 首（1001–1042）、1218 站点缺的条目：分别验证有/无曲谱图时的表现正确。

4. **曲谱可否投屏（本单需给出结论并实现最小版本）**
   - 若投屏窗口已开：曲谱 tab 下点投屏 → 投屏窗口显示曲谱图（整图适应），不支持翻页分段；歌词 tab 下点投屏 → 显示歌词（T5 行为）。
   - 在投屏窗口内无法切换歌词/曲谱（避免误操作），切换只能在主窗口做。

## P1 应做

- 曲谱预加载下一首（缓存 1 张）。
- 键盘 `Ctrl+0` 重置缩放。

## 验收标准

```bash
npm run typecheck && npm test
ls hymns-data/scores/red/0001_0.jpg        # 存在
ls hymns-data/scores/black/0001_0.png      # 存在
```
- 手动：红本第1首切到曲谱 → 显示简谱图，可放大到 200% 并拖动查看细节。
- 手动：1218 第5首切到曲谱 → 正常显示。
- 手动：找一首无曲谱的（红本 1001 短歌）→ 显示「本首暂无曲谱」。
- 手动：曲谱 tab 下投屏 → 投屏显示谱面。
- PM 复验时会实际打开 3 张图核对内容与编号一致。
